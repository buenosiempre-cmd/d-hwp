# D-HWP 반복 검증과 OCR 보강 결과

Issue [#13](https://github.com/buenosiempre-cmd/d-hwp/issues/13)

## 결과

공개 문서 8개와 독립 감사에서 발견한 구조 의미의 오해·서식 기호 오류를 고쳤다. 고정 출처·해시·본문과 정확한 셀의 기대값으로 반복 실행하는 검증 gate를 추가했다. ZIP의 짧은 한국어 README와 상세 Markdown·보고서를 함께 제공한다.

그림은 로컬 Kordoc 4.19.1과 PP-OCR 한국어 모델로 오프라인 인식해 별도 보충 텍스트를 넣는다. 코드·모델 해시 검증, 자격 증명이 없는 별도 프로세스, 자원 한도·취소·실패 표시를 적용했다. 서버 설정으로 켤 수 있고 선택한 프로필은 시작 시 검증한다. 원본 문서와 이미지는 그대로 보존한다.

독립 리뷰에서 OCR 장애 결과가 영구 재사용되는 문제를 발견해 수정했다. OCR 실행 환경 실패는 성공 패키지로 저장하지 않으므로 복구 후 같은 카드에서 다시 요청할 수 있다. 로컬·Cloud 영수증 복구를 각각 검증했다.

## 검증

로컬의 서로 다른 검사 509개와 typecheck, 공개 코퍼스 8개, 실제 OCR 문서 2형식, readiness 7개를 확인했다. 자세한 범위는 [Stage 3](../working/task_m001_13_stage3.md)와 [사용 안내](../../docs/d-hwp-markdown.md)에 기록했다. 실제 OCR은 합성 한글·날짜·금액·인원 4개 문구를 양쪽 형식에서 공백 제외 기준으로 모두 확인했다. 다만 띄어쓰기 오류가 있었으며 무누락 보증이나 범용 정확도 측정이 아니다.

## 남은 실제 운영 단계

동국대 재무팀 Slack 앱의 권한 부여·자격 증명 설정·전용 프로세스 시작·실제 채널 수용은 아직 완료되지 않았다. 기존 준비 사본은 오래된 커밋이므로 새 검증 릴리스가 필요하다. 대표 교내 문서의 승인된 표본 대조도 남아 있다. 반복 검증 완료를 모든 문서의 완전한 이해나 운영 배포 완료로 표현하지 않는다.

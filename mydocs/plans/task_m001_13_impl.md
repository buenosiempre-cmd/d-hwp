# Task #13 구현 계획

현재 사용자의 계속 진행 지시에 따라 아래 세 단계를 수행한다.

1. 공개 코퍼스와 의미 보존: 고정 fixture/출처/해시/독립 기대값 gate, switch·변경 추적·동적 번호·연속 서식 및 가독성 보완.
2. 로컬 OCR과 공유: 정확한 Kordoc 코드·모델 검증, 별도 offline child, 제한·취소·검토 표시, README, 서버 전용 설정·v3 영수증·장애 재시도. 운영자 startup 검증과 Docker smoke에 Markdown 실제 경로 추가.
3. 통합 검증과 게시: 공개8문서/합성 HWP·HWPX/실제OCR/모의Slack/보안/typecheck/CI, 독립 리뷰·재현 결함 수정·재검증, 코드·HTML 보고서와 원격 SHA 인계.

완료 범위와 실제 앱 설치/대표 업무 문서 검증을 분리한다. 앱 자격 증명과 실행권한은 코드 검사로 대체하지 않는다.

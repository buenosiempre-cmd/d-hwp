# Task #13 Stage 1 — 공개 문서 기반 품질 반복

RHWP/Kordoc의 라이선스가 확인된 공개 시험 문서8개(총111,899바이트)를 고정 커밋·SHA256으로 등록했다. 기대값은 README/테스트 및 독립 원본 XML에서 확인했다. 전체 Markdown 검색은 메타데이터에만 남은 값을 잘못 통과시킬 수 있어 본문 영역·정확한 표 셀을 검사한다. 다운로드/해시/캐시 오염 등 단위5개와 offline 공개문서8/8을 통과했다. 원본은 Git에 포함하지 않았다.

실제/합성 재현에서 대체 표현의 중복 오해, OUTLINE 번호 정의 누락, 변경이력 의미 미표시, 동적 PAGE/TOTAL_PAGE 오해, 연속 bold Markdown 기호 충돌을 보완했다. 의미 보존 단위9개와 기존13개, 실제 HWP/HWPX 회귀13개를 통과했다. 기술 검토 항목은 한국어 유형별 건수로 요약하고 상세 원문 속성과 report 기록을 유지한다.

공개 nested-mixed-cell 저장본은 RHWP 조판8쪽/Kordoc 저장정보3쪽 차이가 있었다. 본문·표·그림을 확인했지만 이를 페이지 완전성 성공으로 확대하지 않았다. 번호의 실제 표시도 추측하지 않고 검토 대상으로 남긴다.

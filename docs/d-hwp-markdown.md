# 문서 구조 Markdown과 원본 대조

`/dhwp md <Slack 파일 링크>` 또는 문서 카드의 **문서 Markdown (ZIP)** 버튼으로 요청한다. ZIP 안의 `document.md`를 읽고 `report.json`의 검토 항목을 함께 확인한다. 원본과 개체는 같은 ZIP에 있다. 실제 Slack 설치와 업로드 수용 검증은 아직 별도 진행 사항이다.

## 담는 내용

| 항목 | 표현 |
|---|---|
| 본문·문단 | 문서 구역 순서로 추출, 문자 서식 중 위/아래첨자·취소선 등 의미 표기 |
| 표 | 행/열 격자와 각 셀의 내용, 병합 범위, 중첩 표의 부모 관계 |
| 각주·미주·머리말·꼬리말 | 별도 영역과 본문 참조 |
| 글상자·수식 | 내부 텍스트와 한글 수식 원문. 수식의 의미를 AI로 재작성하지 않음 |
| 필드·링크·메모 정보 | 이름·설명·주소 등 부가 속성 및 해석하지 못한 구조의 원문 |
| 그림·기타 포함 개체 | 해시 이름의 파일로 보존. 지원하는 래스터 그림은 Markdown에서 로컬 참조 |
| 원본 | `source/original.hwp` 또는 `source/original.hwpx`, 바이트와 SHA256 유지 |
| 대조 정보 | XML 텍스트 대응, 표 좌표, 자산 해시, 엔진 손실 보고, 검토 항목 |

HWPX는 원본 ZIP의 XML과 spine 순서를 읽는다. HWP는 RHWP가 읽은 문서를 HWPX 구조로 변환하고 엔진의 손실 보고를 함께 확인한다. 이 해석본도 `source/structure.hwpx`로 제공한다. 미해석 XML 텍스트·속성은 부록에 남기고, 외부 자료를 자동 다운로드하지 않는다. 문서 안의 HTML·링크 문법은 텍스트로 이스케이프한다.

Markdown 2 MiB, 보고서 2 MiB, 포함 개체 합계 25 MiB, 전체 패키지 50 MiB 한도를 적용한다. 구조·압축 해제·XML 처리 한도도 있으며 초과하거나 손상된 입력은 실패 처리한다. 결과를 임의로 잘라서 성공으로 표시하지 않는다. 이전 버전 `.md` 영수증과 새 패키지 영수증을 구분한다.

## 완전성 표시의 의미

`coverage`는 **파싱된 XML의 공백이 아닌 텍스트 노드**와 출력의 대응이다. 100% 대응도 모든 시각 의미, 속성 의미, 그림 속 글자, HWP 엔진이 인식하지 못한 바이너리 내용까지 검증했다는 뜻은 아니다. 원본을 함께 보존하더라도 그 내용을 모두 Markdown으로 해석했다는 뜻은 아니다.

그림 속 글자 OCR, 도형의 의미, 복잡한 배치와 미지원 개체는 원본·PDF와 확인해야 한다. HWP 변환에는 항상 엔진 입력 범위에 대한 검토 항목을 남긴다. `needs_review`는 이런 검토가 남았다는 뜻이다. 현재 서비스는 임의의 모든 문서에 무누락 보증을 제공하지 않는다.

## Kordoc으로 실제 대조한 범위

2026-10-28, Kordoc MCP와 로컬 **4.19.1**에 같은 합성 HWP/HWPX를 입력했다. 머리말을 제거하지 않고, 빈 문단·배치 표·필드 자리표시자 보존 옵션을 켰다. OCR는 실행하지 않았다.

| 비교 항목 | D-HWP | Kordoc 4.19.1 시험 결과 |
|---|---|---|
| 독립 내용 표식 28개 | 두 형식 모두 28개 확인 | HWP 24개, HWPX 23개 확인 |
| 머리말·꼬리말·주석·중첩표·글상자·수식 표식 | 확인 | 확인 |
| 누름틀 안내·설명·이름, 그림 설명 | 확인 | 이 fixture에서는 누락 |
| 링크 주소 | 두 형식 확인 | HWP 확인, HWPX 누락 |

이는 합성 문서 하나를 두 형식으로 직렬화한 결과이며 범용 우열·정확도 점수가 아니다. 수식 표식 비교도 수학적 동등성을 증명하지 않는다. 실제 통합 테스트는 원본·그림의 정확한 바이트/해시와 병합 셀 좌표도 별도로 검사한다. Kordoc 결과는 독립 참고 자료로 사용하며 최종 Markdown에 그대로 합치지 않는다.

별도 설치한 Kordoc 모듈 경로로 재현할 수 있다. 운영 서버에는 Kordoc이나 OCR 모델을 추가하지 않았다.

```sh
node scripts/audit-markdown-kordoc.mjs \
  --module /absolute/path/to/kordoc/dist/index.js \
  --output .cache/kordoc-audit.json
```

다음 품질 검증은 실제 대표 양식의 승인된 표본으로 진행해야 한다. 다단 문서·번호 목록·변경 추적·스캔 첨부·수식·도형을 각각 포함하고, 개인정보가 있는 원본을 저장소나 공개 이슈에 넣지 않는다.

# 구성원 문서 활용 개선

이번 개선은 기존 기능의 공백과 공지·회의자료·본문 복사 업무를 기준으로 정했다. 구성원 설문을 진행한 결과는 아니다. Slack에서 파일을 올리고 같은 스레드에서 결과를 받는 흐름을 유지한다.

## 이번에 추가하는 기능

| 기능 | 쓰임 | 사용 방법 |
|---|---|---|
| 구조 Markdown ZIP | 에이전트와 사람이 주석·표·필드까지 함께 확인 | 문서 Markdown (ZIP), `/dhwp md` |
| 원문 TXT | 행정 시스템에 문구 복사, 개인이 선택한 도구에서 재사용 | 문서 카드 → 형식·쪽 선택 → 원문 TXT |
| 선택 쪽 PNG ZIP | 필요한 공지·붙임·회의자료 쪽만 일괄 다운로드 | 같은 메뉴 → 선택 쪽 PNG ZIP → 예: `1,3-5,12` |
| 형식·쪽 선택 메뉴 | 명령어를 외우지 않고 결과 선택 | 기존 PDF·PNG·Markdown 버튼 옆에서 실행 |

선택은 1~200쪽 중 최대 10쪽이다. 중복 번호는 한 번만 포함하고 오름차순으로 묶는다. 실제 문서에 없는 쪽은 오류로 안내한다. PNG 합계 25 MiB, ZIP 26 MiB, TXT 2 MiB까지이며 임의로 일부만 잘라내지 않는다. 같은 선택을 다시 요청하면 같은 파일 영수증을 재사용한다. 파일 전송이 불확실하면 같은 선택으로 재확인하며 새 결과를 무조건 중복 생성하지 않는다.

TXT는 추출된 원문이다. 표 셀의 순서와 줄바꿈은 검토가 필요하고 표 배치·병합·그림·서명·수식·OCR은 복원하지 않는다. TXT를 만든다고 외부 AI에 원문을 전송하지 않는다. 선택 쪽 ZIP은 기존 첫 3/10쪽 갤러리와 별도로 공유한다.

구조 Markdown은 [별도 안내](d-hwp-markdown.md)에 추출·대조 범위와 Kordoc 실측 결과를 기록한다. 본문 텍스트만 읽던 방식에서 누락되던 주석·수식·머리말·필드 등을 보완했으며, 무누락을 일괄 보증하지 않는다.

## 다음 개선 후보와 판단

| 우선순위 | 후보 | 필요한 확인 |
|---|---|---|
| 다음 | 문서 전체 검색과 문서 정보 | 표·각주·필드가 포함된 구조 Markdown으로 검색. 엔진의 페이지별 텍스트 API는 시험 문서에서 표 셀을 누락하므로 검색 결과의 정확한 쪽 번호를 아직 보장하지 않음 |
| 다음 | 선택한 문단의 동국규정 MCP 근거 찾기 | 사용자가 검색 내용을 확인하고 실행. 규정 제목·조항·출처·확인일과 관련 문단을 함께 제시. 검색 결과와 실제 위반 판단을 구분 |
| 검증 후 | 표 → Excel | 병합 셀, 숫자·날짜, 다단 표와 합계 정확도를 대표 양식으로 검증 |
| 검증 후 | 실제 AI 요약·공문 교정 | 제공자·비용·전송 범위를 정하고 결과와 원문 대조. 기존 편집기 패널은 요청문 준비 기능이므로 자동 요약으로 소개하지 않음 |
| 검증 후 | 스캔 문서 OCR | 별도 엔진과 한글 인식률·개인정보 처리 경로 검증. 현재 텍스트 추출과 혼동하지 않음 |

규정 MCP와의 시너지는 ‘원문 선택 → 관련 규정 검색 → 근거를 보면서 작성·검토’ 순서가 적절하다. 먼저 Slack 변환으로 문서를 다루기 쉽게 하고, 사용자가 고른 내용에 기존 MCP를 연결하는 방식으로 확대한다. 이번 변경이 자동 규정 판정이나 AI 답변 생성을 추가한 것은 아니다.

## 검증 범위

합성 HWP/HWPX와 Slack API 대역으로 변환·권한·모달·영수증 복구를 검사한다. 실제 동국대 재무팀 Slack 설치와 파일 업로드 검증은 별도 기록한다. 새 앱 권한 부여 전에는 사용할 수 있는 운영 앱으로 안내하지 않는다.
